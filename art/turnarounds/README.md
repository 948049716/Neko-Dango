## 建模时必须知道

1. 这些是 AI 生成的造型参考，不是由同一个 3D 模型导出的精确工程正投影。视角、局部体积、花纹及配饰位置可能存在跨视图差异，不能直接当尺寸图描摹。
2. 每张按资产自身排版，跨图显示大小不代表游戏等级尺寸。实际大小以主策划半径配置和公共碰撞代理为准。
3. 概念图毛感较强；运行时仍按美术规范采用哑光主体、简化块面及弱短绒表现，不做实时长毛。
4. T-pose 为绑定姿态意图参考，正式骨骼轴向、关节位置、腋下拓扑与尾根必须在 DCC 中校正；身体保持团状。
5. 容器要保留顶部投放通道。暖桌采用开口木围框，太空舱采用开放顶口；不能照旧氛围图做成阻挡下落的封闭屋顶。
6. 四种容器的美术外轮廓可不同，但共用有效宽高、底部和危险线。图中容器偏宽的展示比例不能替代竖屏玩法的高宽配置。
7. 图中的附属帽子、皇冠、毛线结、泡泡等随角色展示，不代表已经完成独立零件模型交付。拆件图表达模块关系，不保证机械装配精度。
